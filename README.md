# C# Projects

These are some of the projects I completed while learning C# and .NET. Through these projects, I gained experience working with C#, Visual Studio, SQL databases, Entity Framework, and object-oriented programming.

## Projects

### Student Code-First Database

For this project, I created a console application using C# and Entity Framework Core. I used the Code-First approach to create a Student database from C# classes.

The application creates a StudentDB database with a Students table and adds a student record to the database. This project helped me understand how C# applications can communicate with SQL Server using Entity Framework.
